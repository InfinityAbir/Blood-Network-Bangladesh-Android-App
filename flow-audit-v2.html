Medium 10 Notifications Lack Call-Site Try-Catch

Notifications #2-11 (all except Welcome, Report Resolved, Donor Available) have no try-catch at call site. FCM push itself is safe, but any exception in SendNotificationAsync (e.g., DB failure) would propagate up and could fail the parent operation (e.g., creating a blood request).
